# Review Report Template

Use this structure for all review outputs.

```
## [Content Type] Review

**Detected as:** [Blog Post / Social Media / Email / IM / Documentation / Creative]

### Overall Assessment
[2-3 sentences: strengths + biggest issues]

### Scores
| Dimension | Score | Note |
|-----------|-------|------|
...

### AI Pattern Flags
[CONFIRMED flags only — exact quote, location, and suggestion for each.
Debris and scanner hits that survived verification are included here.]

Dismissed as false positives: [count] ([one-line note if any dismissal is instructive])

### Originality / Clarity Flags
[Every concern]

### Top 3 Changes
1. [Specific, actionable]
2. [Specific, actionable]
3. [Specific, actionable]
```
